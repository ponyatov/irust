# 1.4 Tools you’ll need
## Инструменты, которые вам понадобятся

The source code for this book is stored in a public repository hosted on GitHub at https://github.com/brndnmtthws/idiomatic-rust-book.

Для работы с кодом из этой книги и эффективного изучения Rust потребуется набор инструментов, которые стали стандартом в экосистеме языка. Rust отличается развитой инфраструктурой инструментов, которые упрощают разработку, сборку, тестирование и управление зависимостями.

## [[rustup]]
### установщик и менеджер версий Rust

- Устанавливать несколько версий компилятора (`stable`, `beta`, `nightly`)
- Легко переключаться между ними
- Устанавливать компоненты для разных целевых платформ (кросс-компиляция)
- Обновлять Rust одной командой

 **Установка:**
	```sh
	curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
	```

После установки у вас появятся:

- `rustc` — компилятор Rust
- `cargo` — система сборки и менеджер пакетов
- `rustdoc` — генератор документации
- `rustfmt` — автоформатировщик кода
- `clippy` — линтер для улучшения кода

### [[cargo]]

`cargo` — это сердце экосистемы Rust. Он выполняет множество функций:

- Сборка проектов (`cargo build`)
- Запуск тестов (`cargo test`)
- Управление зависимостями (через `Cargo.toml`)
- Создание документации (`cargo doc`)

### базовая структура проекта

```
my_project/
├── Cargo.toml          # Метаданные и зависимости
├── Cargo.lock          # Точные версии зависимостей
├── src/
│   ├── main.rs         # Точка входа для бинарных проектов
│   └── lib.rs          # Точка входа для библиотек
└── tests/              # Интеграционные тесты
```

## [[git/git|git]]
### система контроля версий

- Клонирования репозиториев исходного кода сторонних проектов и библиотек
- Отслеживания изменений в вашем коде
- Создания веток для экспериментов
- Участия в open-source проектах на Rust

**Клонирование репозитория книги:**
```sh
git clone https://github.com/brndnmtthws/idiomatic-rust-book.git
cd idiomatic-rust-book
```

## [[vscode/VSCode|VSCode]]
### Редактор кода/IDE

Для продуктивной работы с Rust рекомендуется использовать редакторы с поддержкой Language Server Protocol (LSP):

- **[[vscode/Visual Studio Code|Visual Studio Code]]** с расширением `rust-analyzer`
- **IntelliJ IDEA** с плагином Rust
- **Neovim/Vim** с конфигурацией для Rust
- **Sublime Text** с LSP-клиентом

### [[rust-analyzer]]

современная реализация LSP-сервера для Rust, которая предоставляет:

- Автодополнение кода
- Переход к определению
- Подсказки по типам
- Рефакторинг
- Диагностику ошибок в реальном времени

### Инструменты отладки и профилирования

- Встроенный интерфейс отладчика в IDE
	- `lldb` или `gdb` с поддержкой Rust
- Профилировщики:
	- `perf` (Linux)
	- `dtrace` (macOS/BSD)
	- `VTune` (Windows/Linux)
	- [[flamegraph]] для визуализации профилей
