# Чему не учат в официальной Rust Book

Официальная документация Rust ([[The Rust Book]]) прекрасно объясняет синтаксис и основные концепции языка. Однако она не всегда отвечает на вопросы, которые возникают при реальной разработке:

- Как организовать крупный проект на Rust?
- Какие паттерны использовать для асинхронного программирования?
- Как проектировать крейты (библиотеки), чтобы их было легко поддерживать?
- Когда использовать `unsafe` и как делать это безопасно?
- Как эффективно тестировать Rust-код?
