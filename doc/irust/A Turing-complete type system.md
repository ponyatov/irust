# 2.1.1 A [[algo/Turing-complete]] type system

Rust’s type system is Turing-complete, and with generics, you can write programs that execute at compile time, which is a neat trick

![[Minsky machine]]

For most people, the main benefits of a Turing-complete type system are the safety and performance features it enables.

> The cons: you can get your compiler in deep sleep or hours of compiling
