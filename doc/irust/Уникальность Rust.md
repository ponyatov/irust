# Уникальность Rust

В отличие от языков с автоматическим управлением памятью или нестрогой типизацией, Rust заставляет нас серьёзно задумываться о следующих аспектах:

1. **Управление памятью и временем жизни**  
    - Rust не использует сборку мусора, что даёт предсказуемость и производительность, но требует явного указания времени жизни объектов. Мы должны научиться работать с системой владения и заимствования, чтобы компилятор мог гарантировать безопасность памяти.

2. **Передача значений между контекстами**  
    - В Rust нельзя просто "передать объект" — нужно решить, передаём ли мы владение, заимствуем изменяемо или неизменно. Этот выбор влияет на архитектуру всего приложения.

3. **Избегание состояний гонки (race conditions)**  
    - Благодаря системе типов и проверкам на этапе компиляции, Rust предотвращает многие многопоточные ошибки. Но для этого нужно правильно проектировать API и использовать подходящие абстракции (`Send`, `Sync`, `Mutex`, `Arc`).

4. **Эргономичность API**  
    - Хороший Rust-код должен быть не только безопасным и быстрым, но и удобным в использовании. Это означает продуманные сигнатуры функций, осмысленные типы ошибок и интуитивно понятные интерфейсы.
